# 模型部署

目标：把可运行的模型组织成可访问、可复现、可维护的服务。

## 学习顺序

- [ ] 模型准备：权重来源、格式、精度与硬件要求。
- [ ] 本地运行：跑通最小推理并记录环境。
- [ ] 服务接口：请求格式、响应格式与流式输出。
- [ ] 容器化：Docker 镜像、依赖和 GPU 运行环境。
- [ ] 服务管理：配置、启动、健康检查与日志。
- [ ] 测试与观测：并发、错误、延迟、资源使用。
- [ ] 进阶部署：多实例、负载均衡与 Kubernetes。

建议文件：`local-deployment.md`、`api-serving.md`、`docker-deployment.md`、`monitoring.md`。

## 实验方向

部署一个最小模型服务，编写请求示例，记录从环境准备到验证成功的完整步骤。实验代码和容器配置放到 `experiments/model-deployment/`。

推理框架负责如何执行计算；本板块负责如何把执行能力接入服务与运行环境。

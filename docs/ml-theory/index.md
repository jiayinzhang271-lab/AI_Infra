# 机器学习理论

目标：理解模型为什么能学习，以及训练和评估背后的基本方法。

## 学习顺序

- [ ] 数学基础：向量、矩阵、概率、导数与梯度。
- [ ] 学习问题：监督学习、无监督学习与任务定义。
- [ ] 损失函数：模型输出与目标之间的误差。
- [ ] 优化：梯度下降、反向传播与学习率。
- [ ] 泛化：训练集、验证集、测试集与过拟合。
- [ ] 神经网络：激活函数、归一化与正则化。
- [ ] 评估方法：指标选择、基线与实验对照。

建议文件：`math-foundations.md`、`loss-and-optimization.md`、`backpropagation.md`、`generalization.md`。

## 实验方向

实现一个简单的回归模型，再训练一个小型神经网络。把数学推导、代码实现和结果放在同一条学习链路里。

涉及数学公式时，先写清符号含义和变量形状，避免只抄公式。

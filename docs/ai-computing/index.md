# AI 计算体系

目标：理解模型运行依赖的硬件与系统资源，建立计算量、显存和通信的分析习惯。

## 学习顺序

- [ ] CPU / GPU：计算单元、并行执行与设备间的数据传输。
- [ ] 张量与矩阵乘法：形状、精度、算子与计算量。
- [ ] 内存层次：显存、缓存、带宽和数据移动。
- [ ] 性能分析：吞吐量、延迟、利用率与瓶颈。
- [ ] CUDA 基础：线程、线程块和简单 Kernel。
- [ ] 多卡计算：通信、数据并行、张量并行与流水线并行。

建议文件：`gpu-basics.md`、`memory-bandwidth.md`、`performance-analysis.md`、`distributed-computing.md`。

## 实验方向

在固定硬件上比较不同矩阵形状和精度的运行耗时。记录设备、软件版本、输入规模与测量方法；实验代码放到 `experiments/ai-computing/`。

## 与其他板块的关系

Transformer 描述模型结构；本板块解释这些结构在硬件上如何执行。推理框架再把这些执行过程组织成高效的服务流程。

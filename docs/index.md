从工具和理论出发，逐步理解模型如何计算、如何推理，以及如何提供稳定的在线服务。

## 从哪里开始

先读[学习路线](guides/learning-roadmap.md)，然后完成[Markdown 学习笔记](tools/markdown.md)中的练习。

各板块目前是学习计划与笔记入口，后续逐篇补充内容。写一篇笔记时，尽量回答三个问题：学到了什么、如何验证、还有哪些疑问。

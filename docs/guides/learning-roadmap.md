# 学习路线

按前置知识安排顺序，不强制按周推进。每个阶段留下一篇笔记和一个可以解释的验证结果。

| 阶段 | 主要学习内容 | 建议产出 |
| --- | --- | --- |
| 1 | Markdown、Git、Python 环境 | 一篇笔记、一次提交、一次本地预览 |
| 2 | 机器学习数学基础、损失、优化、反向传播 | 一个简单模型与结果分析 |
| 3 | Attention、Transformer Block、生成过程 | 最小 Attention 实现与形状说明 |
| 4 | GPU、矩阵乘法、显存、带宽 | 一组计算耗时记录与瓶颈解释 |
| 5 | Prefill / Decode、KV Cache、推理框架 | 一次统一条件下的推理性能实验 |
| 6 | API、Docker、日志、监控 | 一个可复现的模型服务示例 |

AI 计算体系可以从阶段 2 起并行阅读，到阶段 4 再集中实验。工具使用贯穿整个过程。

## 每次学习的闭环

1. 明确问题：这一篇要解决什么疑问？
2. 阅读资料：优先记录官方文档、论文与版本。
3. 写出解释：用自己的话讲清关键概念。
4. 做最小验证：手算、运行代码或观察结果。
5. 记录结论：说明哪些结果支持结论，还有哪些边界。
6. 更新入口：将新笔记加入所在板块和网站导航。

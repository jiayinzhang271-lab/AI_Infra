# Markdown 简明教程

Markdown 的目标就是：**用最简单的纯文本符号，写出带格式的文档**。你只要记住下面这些，就能覆盖 90% 的日常写作。

---

## 1. 标题

用 `#` 表示标题，几个 `#` 就是几级标题。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

注意：`#` 和文字之间要有一个空格。

---

## 2. 段落与换行

- **段落**：直接写文字，空一行表示新段落。
- **换行**：行尾加两个空格再回车，或者直接空一行。

```markdown
这是第一段。

这是第二段。
```

---

## 3. 强调

```markdown
*斜体* 或 _斜体_
**粗体**
***粗斜体***
~~删除线~~
```

效果：  
*斜体*、**粗体**、***粗斜体***、~~删除线~~

---

## 4. 列表

### 无序列表

```markdown
- 苹果
- 香蕉
  - 子项
  - 子项
```

### 有序列表

```markdown
1. 第一步
2. 第二步
3. 第三步
```

### 任务列表

```markdown
- [x] 已完成
- [ ] 未完成
```

---

## 5. 链接与图片

```markdown
[链接文字](https://example.com)
![图片描述](图片地址.png)
```

图片地址可以是本地路径，比如 `assets/image.png`。

---

## 6. 代码

### 行内代码

```markdown
使用 `pip install mkdocs` 安装。
```

### 代码块

用三个反引号包起来，并注明语言：

````markdown
```python
print("Hello, MkDocs")
```
````

在 MkDocs Material 中，代码块会自动高亮，并带复制按钮。

---

## 7. 引用

```markdown
> 这是一段引用。
> 可以写多行。
```

效果：

> 这是一段引用。  
> 可以写多行。

---

## 8. 分割线

```markdown
---
```

会生成一条水平线。

---

## 9. 表格

```markdown
| 命令 | 作用 |
|------|------|
| `mkdocs serve` | 本地预览 |
| `mkdocs build` | 构建静态网站 |
```

效果：

| 命令 | 作用 |
|------|------|
| `mkdocs serve` | 本地预览 |
| `mkdocs build` | 构建静态网站 |

---

## 10. 转义

如果想让 Markdown 符号原样显示，在前面加反斜杠：

```markdown
\*不是斜体\*
```

---

## 11. MkDocs Material 特有语法

这些在 Material 主题里可以直接用，很实用。

### 提示框

```markdown
!!! note "提示"
    这是一条提示信息。

!!! warning "警告"
    这是一条警告信息。
```

### 可折叠内容

```markdown
??? note "点击展开"
    这里是折叠起来的内容。
```

### 带标题的代码块

````markdown
```python title="hello.py"
print("Hello")
```
````

## 13. 学习建议

1. 先记住：`#` 标题、`-` 列表、`**粗体**`、`` `代码` ``、`[链接]()`。
2. 写笔记时直接用，不需要背全。
3. 遇到不会的语法，随时搜“Markdown 表格”“Markdown 链接”。
4. 在 MkDocs 里实时预览，边写边看效果。

| `[文字](链接)` | 超链接 |
| `![描述](图片)` | 插入图片 |
| `` `代码` `` | 行内代码 |
| `` ``` `` | 代码块 |
